# Sayhi Website

A responsive website demo built with React, Vite and Three.js.

## Local development

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

Static output: `dist/client`.

## GitHub Pages

The GitHub Actions workflow builds and publishes the website on pushes to `main`.
Enable GitHub Actions as the source under Settings → Pages.

For a Pages build locally:

```sh
GITHUB_PAGES=true npm run build
```

Source code availability does not grant a license to reuse included brand assets, characters, models or footage.
